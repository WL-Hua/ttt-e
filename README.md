# 导游考试模拟器

双击 `启动考试模拟器.cmd`，保持打开的服务窗口运行，再在这台电脑的任意浏览器打开 `http://127.0.0.1:8765/`。错题本保存在当前 Windows 用户的 `%LOCALAPPDATA%\TourExam\wrong-questions.json`，各浏览器打开同一地址即可共享，页面会定期刷新。服务只监听本机，不支持其他电脑、手机或不同 Windows 用户同步；没有云备份，请定期在错题本中导出备份。

原先直接打开 `index.html` 时的错题仍保存在原浏览器中，不能自动跨浏览器或从 `file:` 地址转移：在原浏览器打开原来的 `index.html`，进入错题本并点击“导出错题本”；然后在 `http://127.0.0.1:8765/` 的错题本中点击“导入错题本”，选择导出的 JSON 文件。导入会合并而不删除原记录。如果之前用多个浏览器做过题，分别导出并导入。后续请统一使用本地服务地址；直接打开文件仍是互相独立的浏览器本地模式。

每张试卷的未完成作答、当前位置、交卷次数和每次交卷的答卷保存在当前 Windows 用户的 `%LOCALAPPDATA%\TourExam\paper-progress.json`，使用同一共享地址的浏览器可以查看、继续和回看已交答卷。在“我的试卷”中选择某次历史答卷即可查看当时的答案、成绩和解析；错题本可切换答题练习或直接查看答案。错题专项练习不计入试卷次数。切换试卷不会丢失已保存的进度。避免同时在多个浏览器编辑同一份试卷；发生冲突时页面会提示并重新读取共享记录。没有云备份，请在“我的试卷”中定期导出试卷进度备份。

原先在共享地址中未交卷的试卷进度会在更新后尝试自动迁移；更早的交卷次数和作答记录没有保存，无法恢复。如果同一试卷已有共享记录，旧进度不会覆盖它，可在“我的试卷”中单独导出未迁移的旧进度作为备份。若之前直接打开 `index.html`，请在原浏览器的原页面中进入“我的试卷”，点击“导出试卷进度”，然后在共享地址中点击“导入试卷进度”，选择导出的 JSON 文件。导入只添加共享端尚不存在的试卷记录，不会覆盖已有记录。旧版只保存了最近一份未完成练习，无法恢复更早的进度。错题专项练习的进度仍只保存在当前浏览器。

试卷本身仍保存在各自浏览器中，手动导入的试卷需要在其他浏览器中分别导入相同文件，才能查看并继续对应进度；清除浏览器站点数据会删除试卷。文件夹内的 DOCX 试卷和没有同名 DOCX 的 PDF 试卷已内置，首次打开或题库更新时自动导入；也可使用“导入试卷”选择其他 DOCX 或含可复制文字的 PDF。试卷和记录均不上传网络。

文档应包含题目、选项和 `正确答案：A` 或 `答案：ABC` 等标记；判断题也支持 `正确答案：对/错`，以及单独一行的题号和 `题干：` 标记。支持 Word 自动编号、同段选项和常见文字编号，但不能保证识别所有排版；无法可靠区分的自动编号选项会提示并排除。扫描图片、需要 OCR 的文档不支持。导入后请对照原卷核对；无法可靠识别的题目会提示并排除，不参与评分，因此试卷实际满分可能低于完整原卷。重新导入同一份试卷时，如果新版本识别出更多题目，会自动更新没有答题记录的旧版本；已有答题记录时会另存完整版本，保留旧试卷和记录。

内置试卷会与 `test` 文件夹中的同名 PDF 按题目内容和顺序核对，不要求 Word 与 PDF 的题号完全一致；核对通过后以 PDF 题号补齐 Word 漏识别的题目。补全题目在试卷卡片和作答页面标明来源；手动导入的文件不会自动使用 PDF 补全。

整卷交卷后显示成绩、正确答案和解析。判断题和单选题每题 0.5 分；多选题每题 1 分，全部选对得 1 分，只选对部分选项得 0.5 分，选错任何选项或未作答得 0 分。满分按本次实际题目计算。答错、漏选或未作答的题目自动加入错题本；错题可反复练习，需手动移除。

在“我的试卷”的“搜索笔试题目”中输入题干或选项关键词，可搜索当前浏览器已加载的全部试卷；展开匹配结果可查看题目选项、正确答案和已有解析，不会改变答题记录。不同试卷中的重复题目会分别显示来源。

“Interview”栏目收录面试问答、汉译英和英译汉练习，支持学习模式（先作答，再显示参考答案）和显示答案模式。面试问答以英文题目为主，中文题目和文档英文题目可展开查看；汉译英练习保留中文题目，避免提前显示英文答案。题目选择和文字草稿仅保存在当前页面中。

Interview 内可用中文或英文关键词搜索所有分类的题目，展开结果查看答案，或点击“前往本题练习”跳转至对应题目。汉译英题目在展开答案前仍显示中文原文；录音进行中需先停止并保存才能跳转。

Interview 的“导游词录音”提供孙中山纪念堂、开平碉楼、陈家祠、丹霞山和南越王博物院（王墓展区）五个景点，各保存一份独立录音，不提供导游词文字。“模拟测试”随机抽取一个景点、全部景点问答题库中不重复的三题、中译外和外译中各一题，以及导游规范、应变能力和综合知识各一题，共九项；不计时、不评分，每项可录音、回放并在有参考答案时展开查看。模拟题目、当前位置和录音只保留在当前浏览器；重新抽题会在确认后删除上一次模拟及其录音，不影响普通练习或导游词录音。避免同时在多个浏览器标签页操作模拟测试。

每道 Interview 题可以录音和回放。点击“开始录音”并允许浏览器使用麦克风，完成后点击“停止并保存录音”；每题保留一份录音，再次录制前会询问是否替换。录音保存在当前浏览器的本地存储中，刷新后仍可回放，但不会跨浏览器或设备共享；清除站点数据会删除录音。录音需要支持 MediaRecorder 的浏览器及安全环境（HTTPS 或本机地址），请在切换题目或离开页面前停止并等待保存。

如需更新自动内置试卷，将 DOCX 或含可复制文字的 PDF 文件放入 `test` 文件夹并关闭占用这些文件的编辑器后，在 PowerShell 中运行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build-papers.ps1`，同时更新 `app.js` 中的内置题库版本号。已有答题记录的试卷不会被直接替换，避免覆盖记录。

PDF.js 3.11.174（Apache License 2.0）和 JSZip 3.10.1（MIT 或 GPLv3）位于 `vendor` 目录。
